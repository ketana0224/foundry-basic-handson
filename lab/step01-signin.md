# Step 1 — サインイン・権限・プロジェクト確認（20分 / 0:10〜0:30）

## 目的
Foundry の作業環境にサインインし、権限とプロジェクトを確認します。

## 手順
1. ブラウザで Microsoft Foundry ポータルを開く。
   - URL: <https://ai.azure.com/>
2. 組織アカウント（Entra ID）でサインインする。
3. サインイン後、画面右上の **「新しい Foundry」トグルが ON** になっていることを確認する（本ハンズオンは新しい Foundry ポータルを使用）。
4. **プロジェクト選択** （例: `proj-...-jyenh`）から、配布された **プロジェクト名** を選んで開く。
   - 一覧に表示されない場合は、右上のディレクトリ/テナントが正しいか確認する。
5. 上部メニューの **ビルド** を開き、左メニューで以下を確認する:
   - **デプロイ**: 使用するチャットモデルがデプロイ済みか（後の Step 2 で使用）
   - **エージェント**: 既存エージェント一覧が見えるか（プロジェクトが正しいかの確認）
6. 権限を確認する（自分のロール）。**ビルド → エージェント → 右上の「新しいエージェント」** が選べるかで、Agent 作成権限があるかを自分で確認する。
   - 選べてエージェント作成画面に進めれば OK（**Cognitive Services User** ロールが Foundry アカウント スコープで付与されている状態）。
   - 選べない/「権限がありません」と出る場合は講師に連絡する。
   - 補足: 「Contributor」は管理プレーンのみで dataActions を含まず、「Azure AI User」はこのテナントに未展開のため、いずれもエージェント構築には不十分。

## 完了チェック
- [ ] 正しいプロジェクトを開けている
- [ ] モデルがデプロイ済みであることを確認できた
- [ ] Agent 作成メニューにアクセスできる

## UI が違うとき
- 右上の **「新しい Foundry」トグル** が OFF だと旧ポータル表示になる。本手順の画面名（ビルド/操作 タブ等）と合わない場合はトグルを ON にする。
- サインイン直後に複数プロジェクトが出る場合は、接続情報シートの **プロジェクト名** で選択。
- 「権限がありません」と出たら、[Step 12 — トラブルバッファ](step12-troubleshoot.md) で RBAC を確認。
