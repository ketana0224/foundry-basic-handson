# Step 4 — MCP サーバーの有効化・接続（20分 / 1:25〜1:45）

> **📌 このステップで行うこと**
> MCP サーバーへの接続を **自分で新規作成** します。
> 下記のリモート MCP サーバー エンドポイントを指定し、**非認証** で接続します。

## 目的
リモート MCP（Model Context Protocol）サーバーへの接続を新規作成して Agent に追加し、外部ツール連携を体験します。

## 手順
1. 作成したエージェントを開き、設定ペインの **ツール（Tools）** を開く。
2. **ツールの追加（Add tool）** から **MCP**（Model Context Protocol）を選択する。
3. **モデル コンテキスト プロトコル ツールの追加** ダイアログで以下を入力し、**接続** を押す。
   - **名前**: 一意の名前を指定。受講者どうしで重複しないよう、**自分のユーザー名を含める**（例: `edinet-mcp-user01` … `edinet-mcp-user11`。`userXX` は割り当てられた番号に置き換える）。
   - **リモート MCP サーバー エンドポイント**:
     ```
     https://apim-aigateway-eastus2.azure-api.net/edinetdb/mcp
     ```
   - **認証**: 既定は **キーベース** ですが、ドロップダウンから **非認証** を選択する。
     - ※ **非認証** を選ぶと **資格情報** の入力は不要になります（キーベースを選んだ場合のみキーと値のペアを入力）。
   - （注）ダイアログ上部に「サード パーティのサービスは Microsoft 以外の製品」である旨の注意書きが表示されます。内容を確認して進めます。
4. 接続後、エージェントが MCP ツールを認識しているか確認する。
   - 追加した **MCP サーバー** の右側の **⋮（メニュー）→ 構成** を開く。
   - 「このエージェントに対するこの MCP サーバーのツールの承認設定」で **すべてのツールを常に自動承認する** を選ぶ。
   - ※ 既定は **ツールを自動承認しない** で、実行のたびに承認ダイアログが表示される。ハンズオンでは自動承認にしておくとスムーズ。
   - 特定のツールだけ自動承認したい場合は **特定のツールを常に自動承認する** を選択する。
5. MCP ツールを使う想定の質問を投げて動作を確認する:
   - 例: 「トヨタ自動車の直近5年間の売上推移と収益性を分析して」
   - 例: 「ROE15%以上、PBR1倍以下の割安高収益企業を探して」
6. 回答に MCP ツールの利用結果が反映されているか観察する。

## UI が違うとき
- MCP ツールが追加できない場合は、エンドポイント URL の綴りと末尾 `/mcp` を確認。
- 認証エラーが出たら [Step 12 — トラブルバッファ](step12-troubleshoot.md) を参照。
