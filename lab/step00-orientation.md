## 目的
本日のゴールと成果物、進め方を共有します。

> 本ハンズオンは **新しい Foundry ポータル**（<https://ai.azure.com/>、右上の「新しい Foundry」トグルが **ON**）を前提に記載しています。上部メニューの **ビルド**（エージェント/モデル/ツール/ナレッジ 等）と **操作**（トレース）を中心に操作します。

## 進め方（講師デモ + 説明）
1. 本日のゴールを確認する: 「ポータル上で単一 Agent を作成し、Web Search と Foundry IQ で根拠付き回答を行い、トレース閲覧と手動評価で運用の入口を体験する」。
2. 完成イメージを見せる: 「Agent に質問 → Foundry IQ の社内資料を根拠にして回答 → その裏側のトレースを確認 → 回答品質を評価」という一連の流れ。
3. 本日の成果物を確認する:
   - instructions を設定した単一 Agent
   - Web Search / Foundry IQ を使った根拠付き回答
   - 手動評価シート（正常例・失敗例・引用有無）
   - トレース閲覧結果 1件以上
   - クリーンアップ確認表
4. 用語の最小限の整理:
   - **プロジェクト**: Foundry の作業単位。
   - **モデル**: 回答を生成する頭脳（例: GPT 系）。
   - **Agent**: モデル + 指示（instructions）+ ツール（Web Search / Foundry IQ / MCP など）をまとめたもの。
   - **ツール**: Agent が外部知識・機能にアクセスする手段。
   - **トレース**: Agent の内部処理（どのツールを呼んだか等）の記録。
