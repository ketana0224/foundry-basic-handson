# Step 3 — 単一 Agent 作成（25分 / 0:50〜1:15）

⬅️ 前へ: [Step 2 — モデルとプレイグラウンド](step02-model-playground.md) ｜ 🏠 [目次](README.md) ｜ ➡️ 次へ: [Step 4 — MCP サーバーの有効化・接続](step04-mcp.md)

---

## 目的
instructions を設定した Agent を作成します。Foundry Agent Service では **Web Search が既定で有効** になる想定です（構成により異なる場合あり）。

## 手順
1. 上部メニュー **ビルド** → 左メニュー **エージェント** を開き、右上の **新しいエージェント** から **エージェントの構築** を選択する。
2. 基本情報を設定する:
   - **名前**: `handson-agent-<自分の名前>`（受講者ごとに一意にする）
   - **モデル**: Step 2 で使ったチャットモデルを選択
3. **指示（instructions）** を入力する。以下をベースに設定:
   ```
   あなたは社内向けアシスタントです。
   - 回答は日本語で、簡潔かつ丁寧に。
   - 事実に基づき、根拠がある場合は出典を必ず示してください。
   - 分からないことは「分かりません」と正直に答え、推測で断定しないでください。
   - 最新情報が必要な場合は Web Search を活用してください。
   ```
4. エージェント設定内の **ツール（Tools）** を確認する:
   - **Web Search** が有効になっているか確認する（既定で有効の想定。無効なら「ツールの追加」から有効化する）。
   - 出典: <https://learn.microsoft.com/en-us/azure/foundry/agents/how-to/tools/web-search>
5. エージェントを保存する。
6. エージェント詳細画面右側の **プレイグラウンド（テストチャット）** で動作確認:
   - 質問例: 「Microsoft Foundry とは何か、簡単に教えてください。」
   - 質問例（最新情報）: 「今日のニュースを教えて」
7. 回答に出典（引用リンク）が付くかを確認する。

## 完了チェック
- [ ] instructions を設定した Agent を作成できた
- [ ] Web Search の有効状態を確認できた
- [ ] Agent に質問して回答を得られた
- [ ] （可能なら）Web Search 由来の出典が回答に付いた

## UI が違うとき
- 「ツール」はエージェント詳細の設定ペイン内にある（左メニューの **ツール** はツール一覧の管理用）。
- Web Search のトグルが見つからない場合は [Step 12 — トラブルバッファ](step12-troubleshoot.md) で確認。
