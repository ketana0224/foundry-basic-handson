# Step 6 — トレース閲覧（15分 / 2:30〜2:45）

⬅️ 前へ: [Step 5 — Foundry IQ で根拠付き回答](step05-foundry-iq.md) ｜ 🏠 [目次](README.md) ｜ ➡️ 次へ: [Step 7 — 手動評価](step07-eval.md)

---

## 目的
Agent の内部処理（どのツールを呼び、どんな入出力だったか）をトレースで確認し、運用・デバッグの入口を体験します。

## 手順
1. 上部メニュー **操作** を開き、**トレース（Observability / Tracing）** 画面を開く。
   - エージェント詳細ページ上部の「トレース」リンクからも開ける。
   - 出典: <https://learn.microsoft.com/en-us/azure/ai-foundry/concepts/observability>
2. 直前の Step 5 で投げた質問に対応するトレースを1件開く。
3. トレースの中身を確認する:
   - どのツール（Web Search / Foundry IQ / MCP）が呼ばれたか
   - ツールへの入力・出力
   - 各処理にかかった時間
4. **正常例**と**失敗例**のトレースを見比べ、失敗の原因（ツール未使用・検索ヒットなし等）を推測する。

## 完了チェック
- [ ] トレースを1件以上開いて中身を確認できた
- [ ] どのツールが呼ばれたかを読み取れた
- [ ] 失敗例のトレースから原因を推測できた（あれば）

## UI が違うとき
- トレースが表示されるまで数秒〜数十秒かかる場合がある。
- 表示されない場合は [Step 12 — トラブルバッファ](step12-troubleshoot.md) を確認。
