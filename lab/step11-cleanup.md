# Step 11 — クリーンアップ（10分 / 2:55〜3:05）

⬅️ 前へ: [Step 10 — Hosted Agent デプロイ](step10-hosted-agent.md) ｜ 🏠 [目次](README.md) ｜ ➡️ 次へ: [Step 12 — トラブルバッファ](step12-troubleshoot.md)

---

## 目的
本日作成したリソースを整理し、不要な課金・混乱を防ぎます。

> **📌 注意**
> MCP サーバーや Foundry IQ のナレッジ（**事前準備済み**の共有リソース）は **削除しないでください**。
> 削除対象は「本日あなたが作成したもの」だけです。

## 手順
1. 自分が作成した **Agent**（`handson-agent-<自分の名前>`）を確認する。
2. 運用ルールに従って処理する:
   - **削除する場合**: Agent を選択して削除する。
   - **残す場合**: 講師の指示に従い、名前や状態をメモして残す。
3. 自分で追加した接続・テスト用の設定があれば元に戻す。
4. 共有リソース（MCP・Foundry IQ ナレッジ・モデルデプロイ）に**手を加えていない**ことを確認する。

## クリーンアップ確認表
| 項目 | 対応 | 完了 |
|------|------|------|
| 自作 Agent | 削除 / 残す（指示に従う） | ☐ |
| 追加した接続・設定 | 元に戻した | ☐ |
| 共有リソース | 触っていない | ☐ |

## 完了チェック
- [ ] 自作リソースを整理した
- [ ] 共有リソースを削除・変更していないことを確認した
