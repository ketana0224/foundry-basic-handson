# Step 2 — モデルとプレイグラウンド（20分 / 0:30〜0:50）

## 目的
モデルを選び、プレイグラウンドで基本応答を確認します（Agent を作る前にモデル単体の挙動を体験）。

> 新しい Foundry のプレイグラウンドでは **Web 検索（Web Search）が既定で有効** な場合があります（左ペインの「ツール」に「Web 検索」が表示）。その場合、最新情報を尋ねても出典付きで回答されます。

## 手順
1. 上部メニューの **ビルド** を開き、左メニューから **デプロイ** を開く。
2. デプロイ済みのチャットモデルを選ぶ。
   - 新規に探す場合は上部 **検出** のモデルカタログから検索できる（今回はデプロイ済みを使用）。
3. モデルを開き、**プレイグラウンド（チャット）** で試す。
4. 左ペインの **ツール** を見、「Web 検索」が有効かどうかを確認する。
   - ない場合は **追加** から「Web 検索」を有効にする。
5. 次の質問を入力して応答を確認する:
   - 例1: 「あなたは何ができますか？簡潔に教えてください。」
   - 例2: 「今日の東京の天気は？」
     - **Web 検索が有効なら** → 最新天気を **出典（引用）付き** で回答することを確認。
     - **素のモデルの限界を体験したい場合** → ツールの「Web 検索」を一旦 **オフ**（削除/無効化）にし、ポータル右上の吹き出し **＋** ボタンで新規チャットを開いて同じ質問をすると、最新情報に答えられない（または古い）ことを確認できる。

## 完了チェック
- [ ] プレイグラウンドでモデルに質問し、応答を得られた
- [ ] Web 検索の有効/無効で回答が変わる（最新情報・出典の有無）ことを理解した
