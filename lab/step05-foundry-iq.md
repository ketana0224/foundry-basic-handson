# Step 5 — Foundry IQ で根拠付き回答（25分 / 1:45〜2:10）

⬅️ 前へ: [Step 4 — MCP サーバーの有効化・接続](step04-mcp.md) ｜ 🏠 [目次](README.md) ｜ ➡️ 次へ: [Step 6 — トレース閲覧](step06-trace.md)

---

> **📌 事前準備済みの前提**
> Foundry IQ のナレッジ（インデックス化された社内資料・ナレッジソース）は **講師側で事前準備済み** です。
> 本ステップでは「準備済みのナレッジを Agent に**接続して根拠付き回答をさせる**」ことだけを行います。
> ナレッジソース／インデックスの作り方は **別途案内** します。

## 目的
事前準備済みの Foundry IQ ナレッジを Agent に接続し、社内資料を根拠にした回答（グラウンディング）を体験します。

## 手順
1. エージェントの設定ペインで **ナレッジ（Knowledge）** を開く。
   - 上部 **ビルド** → 左メニュー **ナレッジ** でナレッジ一覧を確認できる（ハンズオンでは右クリック-新しいウィンドウで開くで確認してください）
   - 一覧画面で **「検索サービスのセットアップに失敗しました（Azure AI Search サービスをプロビジョニングできませんでした）」** というバナーが出ることがある。これは Foundry IQ が**プロジェクト専用の Azure AI Search を新規に自動作成しようとして失敗している**メッセージ。本ハンズオンでは **既存の Azure AI Search を使う**ため新規作成は不要で、このバナーは **想定内なので無視してよい**。
2. エージェントの構築にある**ナレッジ**の **追加**（追加 ∨）を開く。
3. **使用可能なナレッジ ベース** の一覧から、事前準備済みの **kb-custom-index-ir**（企業の IR・統合報告書の情報）を選ぶ。
   - 一覧には `kb-custom-index-ir`（`srch-ketana-prod-centralus - kb-kb-custom-index-ir-rhdhy`）が表示される想定。表示されない場合は **Foundry IQ に接続する** を選び、講師に確認。
4. ナレッジ検索を優先させるため、エージェントの **指示（Instructions）** を以下に書き換える:

   ```text
   あなたは社内向けアシスタントです。
   - 回答は日本語で、簡潔かつ丁寧に。
   - 事実に基づき、根拠がある場合は出典を必ず示してください。
   - 分からないことは「分かりません」と正直に答え、推測で断定しないでください。
   - ナレッジ検索を優先して、有効な回答が無い場合のみWeb Search を活用してください。
   ```

5. エージェントを保存する。
6. ナレッジに含まれる内容について質問し、根拠付き回答を確認する:

   **簡単な質問**
   - 東急不動産の社内ベンチャー制度の名前は？
     - 期待回答：STEP
   - 2023年で即席めんの一人当たりの年間消費量が最も多い国はどこか。
     - 期待回答：ベトナム

   **複雑な質問（組み合わせ質問）**
   - 2023年の即席めんの一人当たりの年間消費量が最も大きい国と日本の差分は何食か。
     - 期待回答：34.0食
   - 株式会社キッツの2023年度売上高構成比が2番目に高い事業の製造・販売会社を全て上げよ。（回答には株式会社も含めること）
     - 期待回答：株式会社キッツメタルワークス、北東技研工業株式会社
7. 回答に **出典（引用）** が付くことを確認する。
8. あえて **ナレッジに含まれない質問** も投げ、挙動を観察する。
   - このナレッジは公開されている以下企業の統合報告書で構成されています:
     - 4℃-IR-Report2024_rev2.pdf
     - GRORY-IR-2024-RSaj.pdf

     - Kitz_Corporate_Report_2024_J_A4_single.pdf
     - NISSAN-サステナビリティRep-DB24_J_All.pdf
